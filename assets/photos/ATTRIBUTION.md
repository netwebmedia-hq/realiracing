# RealiRacing — photo attribution

Every photograph on this site is listed here with its author, its licence and the
page it came from. The site renders the same three values in the caption under
each picture, and `_ci/validate-blog-photo-attribution.mjs` fails the build if a
published page shows a file this table does not cover.

**Only attribution-only licences are allowed** — CC BY 2.0/3.0/4.0, CC0 and the
Public Domain Mark. ShareAlike is excluded on purpose: these files are resized
for the web and we will not argue about whether that makes a derivative work.
All-rights-reserved press photos are never allowed, however permissive a
publisher's media guidelines read, because every page on this site is commercial
use. (EntrePoker learned that one the expensive way — see
`entrepoker/assets/photos/ATTRIBUTION.md`.)

16 file(s): 10 sourced under an open licence, 6 produced by NetWebMedia.

Regenerate this file with:

```bash
node _deploy/fetch-blog-photos.js --property <name> --write-attribution
```
